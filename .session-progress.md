## Result: 26 tests, 23 errors, 0 passes, 0 failures

All 23 errors share root cause:

    RuntimeException: Mock server admin request failed: cURL error 28:
    Connection timed out after 10003 milliseconds
    .../tests/_helpers/class-outpost-mock-server.php:189
    .../tests/_helpers/class-outpost-mock-server.php:43

Line 43 is `Outpost_Mock_Server::reset()` (called in every test's setUp). Line 189 is the cURL POST to WireMock's admin port.

## Root cause

`.wp-env.json` sets `OUTPOST_TEST_MOCK_SERVER_URL=http://172.17.0.1:8080` for the tests environment. On Linux (GitHub Actions ubuntu-latest), `172.17.0.1` is the docker bridge gateway → works. **On macOS Docker Desktop, that IP isn't routable from inside the tests-cli container.** The host is reachable via `host.docker.internal` on macOS instead.

This is an environmental difference between local macOS and CI Linux. **Not a fault in the seam fix or in production code.** CI on Linux would not hit this issue.

# Screenshots

Inventory of the screenshots the user documentation needs. Images live in `docs/assets/screenshots/` and are referenced from the other pages with relative paths.

Screenshots come from two sources. The repeatable capture script (`npm run screenshots:docs`, which runs `scripts/capture-docs-screenshots.cjs` against a disposable WordPress Playground — no Docker needed) generates the admin screens and the composer sign-in view. The remaining rows need a manual capture: they require a completed IndieAuth sign-in, connected providers, or a real phone (the composer is mobile-first, so capture mobile-surface shots on a phone or a mobile-sized viewport).
